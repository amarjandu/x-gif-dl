# x-gif-dl

A small extension that is used to download gifs from x.com

## About

This can be used to download gifs from `x.com`.
Because under the hood twitter/x serves gifs as video files, we download the video, then use [`ffmpeg-wasm`](https://ffmpegwasm.netlify.app/) to convert the video to a gif.

<img src="about.png" alt="about" width=300>

Click `Generate Gif` and enjoy!
